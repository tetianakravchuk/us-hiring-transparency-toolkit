# U.S. hiring request builder

Use this decision process before drafting a request.

## Inputs
- Applicant state of residence (at application and now)
- Job location / remote eligibility
- Employer name and relevant legal entity
- Application and rejection dates
- Whether a third-party background report was involved
- Whether an automated assessment was disclosed
- Desired outcome: feedback, access, correction, or complaint

## Decision flow
1. **Check official sources** for a specific law, jurisdiction, coverage thresholds, employment exclusions, and current effective dates.
2. If a verified right applies, draft a narrowly scoped statutory request and identify the exact basis.
3. If no applicable right is established, draft a courteous voluntary request. Do not misrepresent a request as mandatory.
4. If a covered third-party consumer report caused adverse action, review the FCRA notice and report rights separately.
5. If discrimination is suspected, point to the EEOC or relevant state agency; don't imply an access request extends filing deadlines.
6. Ask about AI screening as a separate question, not an assumed legal entitlement.

## Output
- Jurisdiction and applicability: verified / uncertain / not established
- Official source links and date checked
- Appropriate email/portal (verified, never guessed)
- Editable request
- What the employer might lawfully withhold
- Follow-up plan

Do not paste personally identifying application records into public issues or commits.
