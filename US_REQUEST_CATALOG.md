# What U.S. applicants can ask employers for

**Askable** does not mean **legally obtainable**.

| Requested item | Possible path | Caution |
|---|---|---|
| Application and profile data | Applicable state access law or voluntary request | Employment exclusions and coverage vary |
| Recruiter notes / interview ratings | Applicable access law or voluntary request | Confidential evaluations and exemptions may apply |
| ATS tags, rejection codes, automated scores | Applicable access law or voluntary request | No universal right to algorithmic explanation |
| Whether automated screening was used | Candidate notice law where applicable or voluntary request | Jurisdiction and tool definition matter |
| Third-party background report | FCRA rights where covered | Not every ATS assessment is a consumer report |
| Inaccurate applicant personal information | Applicable correction right or voluntary request | Exceptions and verification apply |
| Job pay range | Specific state/local pay transparency requirements | Usually depends on location and posting scope |
| Exact reason for rejection | Voluntary feedback request | Generally no universal disclosure obligation |
| Suspected discriminatory treatment | EEOC/state agency process | Strict deadlines may apply |
